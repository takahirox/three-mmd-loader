## Source and changes since 0.1.0

The exact runtime source is main commit
`62d1476f45258f0063ceccdcb5ad46455d3ab218` (PR #93).
Preparation started from GitWeave checkpoint
`04e594273225862683a22ba4f2d0e2ff6fcd95be`, whose tree matches that main
commit. This release changes metadata, documentation and package validation;
it does not change the runtime source. The published 0.1.0 registry metadata
identifies `12f36efc9500c65c60783ca66268ce6966d139e3` as its `gitHead`.

Material updates included in this candidate:

- Optional packaged Bullet JS/WASM, manifest and all eight redistributable
  license files, pinned to unmodified official Bullet source commit
  `d3afe76132fc76b0f9b2359cbaef47a3766e7fbb`, built with Emscripten 4.0.10.
  Examples and primary regression tests use this backend (PR #87); consumer
  Ammo remains externally initialized and optional. The
  [pinned manifest](../../examples/vendor/bullet/manifest.json) records the
  source, recipe, binary and license hashes.
- Classic Worker physics and its packaged runtime; transferable transport on
  ordinary pages, optional shared memory with isolation, diagnostics and
  recovery to initialized main-thread Ammo.
- Animation influence ramp during initial physics warmup (PR #91), including
  Worker startup, pause/edit and recovery behavior.
- MotionState-first kinematic synchronization (PR #89), timestep/substep,
  damping, joint rotation, linked collision and type-2 integration work.
- Unified PMD/PMX physics synchronization policy through PR #93, preserving
  format-specific normalization and PMX animation phase information.
- IK limit handling, MMD material/color composition and public Gene Light PMX
  and Worker Examples improvements since 0.1.0.

**Known non-blocking limitation:** rare severe PMD physics instability is
still under investigation. The maintainer has performed limited motion
checks and reports no obvious regression; this is not confirmation of a fix.
Automated short-run startup/finite-value checks do not establish subjective
or long-running physics stability. Further visual approval or physics fixes
are not prerequisites for this release preparation.
