Standalone MMD examples

Three.js scenes using this repository's MMD loader and animation helper.

  • Model and animation — VMD motion, IK, physics, and outlines.
  • Audio and camera animation — synchronized model, camera, and music.
  • Poses — load and apply VPD poses.

Before opening a scene, run npm run examples:assets once to download its assets locally.

Read the setup, asset terms, and credits. The downloaded MMD assets have their own terms and are excluded from Git and the npm package.
